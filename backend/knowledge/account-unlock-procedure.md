# Account Unlock Procedure
Demo / Synthetic IT Policy. Owner: Identity Support. Version 1.0.

## Locked account
Stop repeated sign-in attempts. Use the approved self-service account recovery page if available. If recovery fails, contact IT support with your employee identifier and the displayed error. Support verifies identity before unlocking the account. Never include passwords or MFA codes in a ticket.

## Suspicious activity
If the lockout follows unexpected MFA prompts or unfamiliar sign-in alerts, report a possible security incident. Do not reset or dismiss security notifications without recording them for support.
