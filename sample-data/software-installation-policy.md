# Software Installation Policy
Demo / Synthetic IT Policy. Owner: IT Governance. Version 1.0.

## Approval required
Employees may install software from the approved company software catalog. Software outside the catalog requires an IT service request, a business justification, and manager approval. IT reviews licensing and security before installation. Employees must not bypass device management or use personal administrator accounts.

## Prohibited actions
Unlicensed software and downloads from unverified sources are prohibited. A free license does not remove the approval requirement for software outside the catalog.
