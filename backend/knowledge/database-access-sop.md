# Database Access Request SOP
Demo / Synthetic IT Policy. Owner: Data Platform. Version 1.0.

## Request process
Submit a database access ticket specifying the database, environment, required role, business purpose, and requested expiry date. Attach approvals from your manager and the data owner. The database administrator provisions the least privilege necessary after both approvals.

## Access conditions
Production access requires MFA and an approved managed device. Read-only access is the default. Write access requires an explicit data-owner justification. Access expires on the approved date and must be requested again if still needed. Never share database credentials.
